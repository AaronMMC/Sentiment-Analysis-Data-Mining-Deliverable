# Requirements for "Public Discourse and Sentiment Analysis on the Impeachment Issue of VP Sara Duterte"

#
# NOTE for students (oral defense): each library below maps to one project stage.
# - streamlit      -> the GUI wizard itself
# - pandas/numpy   -> data tables and numeric work
# - scikit-learn   -> TF-IDF, stratified splits, 10-fold CV, precision/recall/F1
# - gensim         -> LDA topic modeling + Coherence (Cv)
# - nltk           -> tokenization, stopwords, lemmatization word lists
# - vaderSentiment -> baseline rule-based sentiment (English-tuned, we extend it)
# - plotly         -> interactive heatmaps / bar charts
# - matplotlib/seaborn -> static fallback charts (confusion matrix etc.)
# - praw           -> Reddit API (read-only, respects rate limits)
# - google-api-python-client -> YouTube Data API v3 (commentThreads.list)
# - openpyxl       -> reading Excel uploads via pandas
# - stopwordsiso   -> external Tagalog (tl) + English stopwords (stopwords-iso)
# - transformers/torch/accelerate/safetensors -> AUXILIARY transformer
#   comparison track only (TagaSenti, Tagalog/Taglish). The graded sentiment
#   model stays rule-based (VADER + lexicon) per the project brief.
#   GPU: install the CUDA build of torch for your card, e.g.
#     py -m pip install torch --index-url https://download.pytorch.org/whl/cu121
#   (RTX 4060 target). CPU fallback works without it, just slower.
